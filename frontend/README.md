# SKYGUARD Frontend Subsystem

## Responsibilities

The frontend subsystem provides the real-time operational command-center dashboard for weather station monitoring, evidence inspection, and scenario playback.

## Critical Architectural Constraint

> [!IMPORTANT]
> **Zero Client-Side Diagnosis**:
> The dashboard is strictly an observational and presentation interface. It **never** calculates, infers, or independently creates a diagnostic state. It solely renders the decision object (`state`, `evidence`, `confidence`, `reason`, `action`) generated by the backend decision engine.

## Planned Features (To Be Implemented in M2)

- **Station Network Overview**: High-level status cards and regional geographical map showing current operational states (`NORMAL`, `WORLD`, `SENSOR`, `BOTH`, `UNKNOWN`).
- **Station Diagnostic Deep-Dive**: Multi-parameter time-series charts (temperature, humidity, pressure), live evidence breakdown cards, provenance inspector, and recommended actions.
- **Scenario Playback Controller**: Interactive controls to simulate atmospheric microbursts, sensor drift, power failures, or ambiguous weather fronts.
